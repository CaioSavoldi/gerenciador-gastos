# Gerenciador de Gastos

Programa de terminal em Python para controlar gastos pessoais. Os dados ficam salvos em um arquivo JSON.

## Funcionalidades

- Adicionar gastos com descrição, valor, categoria e data
- Listar todos os gastos
- Ver o total geral e o total por categoria

## Como rodar

1. Instale o Python 3.

2. Clone o repositório:
git clone https://github.com/CaioSavoldi/gerenciador-gastos.git

3. Entre na pasta e execute:
python main.py

## Tecnologias

Python, módulos padrão `json`, `os` e `datetime`.
